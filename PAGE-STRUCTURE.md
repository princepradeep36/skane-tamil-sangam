# Public page structure

- `/index.html` — Skåne Tamil Sangam home
- `/about.html` — About Us
- `/events.html` — Event & service gateway
- `/contact.html` — Contact
- `/event-registration.html` — Diwali Celebration 2026 registration (single canonical event registration page)
- `/food/index.html` — Click2Eat customer hub
- `/food/menu.html` — Create food order
- `/food/payment.html` — Pending food payments
- `/food/receipts.html` — Paid food receipts
- `/food/login.html` — Vendor/admin login only

Event administration remains under `/food/admin*.html` because it uses the integrated Click2Eat/admin backend.
